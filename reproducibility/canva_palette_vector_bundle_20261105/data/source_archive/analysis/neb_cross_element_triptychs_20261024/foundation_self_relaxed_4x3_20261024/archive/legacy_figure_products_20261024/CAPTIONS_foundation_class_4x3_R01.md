# Foundation-model class ensemble 4×3

**Figure X | Foundation-model class ensembles across Cr, Cu, Li, and Na migration paths.** Rows show Cr, Cu, Li, and Na; columns show in-gap diffusion, gap→QL, and within-QL paths. Each colored curve is the pointwise mean relative energy of the local Foundation checkpoints in that class; hollow circles show the class mean and the translucent band is the pointwise sample standard deviation across checkpoints. Individual model markers are omitted. The classes are MACE-MP (five checkpoints: Agnesi medium and density-stress small/medium/large, plus MP-0b3 medium), MACE-OMAT-0 (two checkpoints), and MACE-MH (two checkpoints for Cu/Li/Na; one available checkpoint for Cr), following the official ACEsuit release mapping. Cr uses the canonical 81-atom, ten-image fixed-path campaign profiles materialized in TIER1; its MACE-MH-1 fixed-path result is unavailable and is not imputed. The dashed black curve is the screened QE path-table reference for Cu/Li/Na; the Cr QE path-table source is unavailable in this checkout and is intentionally omitted from the Cr row. All retained QE paths carry SCF-convergence warnings; the reference is therefore diagnostic and is not presented as converged DFT ground truth or as a publication-grade activation barrier. All colored curves are fixed-path single-point evaluations and are not self-relaxed MLFF-NEB results.
