# Foundation-model class ensemble 4×3 (R03)

**Figure X | Foundation-model class ensembles and screened QE references across Cr, Cu, Li, and Na migration paths.** Rows show Cr, Cu, Li, and Na; columns show in-gap diffusion, gap→QL, and within-QL paths. Each colored curve is the pointwise mean relative energy of nine local Foundation checkpoints in that class; hollow circles show the class mean and the translucent band is the pointwise sample standard deviation across checkpoints. Individual model markers are omitted. The classes are MACE-MP (five checkpoints), MACE-OMAT-0 (two checkpoints), and MACE-MH (two checkpoints), following the official ACEsuit release mapping. Cr uses the canonical 81-atom, ten-image fixed-path campaign inputs, and its screened QE reference is now shown with the same dashed black line and hollow-diamond markers as the other rows. The Cr MACE-MH-1 trace was added by a local MACE fixed-path single-point evaluation with the `omat_pbe` head; it is finite and reproducible but remains diagnostic. All four QE reference paths carry SCF-convergence warnings; they are screened diagnostic references and are not presented as unconditional converged DFT ground truth or publication-grade activation barriers. All colored curves are fixed-path single-point evaluations and are not self-relaxed MLFF-NEB results.
