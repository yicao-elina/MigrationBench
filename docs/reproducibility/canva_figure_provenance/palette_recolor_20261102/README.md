# Canva palette recolor campaign — 2026-11-02

This is an additive palette-update package for the locally catalogued historical
Canva figure set `CANVA-P01`–`CANVA-P10`.

The current Canva design `DAHZXpLtN6U` remains `REAUTH_REQUIRED`; its page count
and thumbnails are not asserted here. P03/P04 are local reconstructions because
the exact historical Canva PDFs are pointer-only. P06–P10 use the local rendered
figure artifacts where their raw inputs remain external or incomplete; those
boundaries are retained in `RENDER_MANIFEST.json`.

The original source files and prior rendered outputs are not overwritten. The
new PNG/SVG/PDF-or-source-vector assets live under `figures/CANVA-P##/`.
