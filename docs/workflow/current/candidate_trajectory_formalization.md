# Candidate Trajectory Formalization

The executable numerical contract, endpoint state machine, coverage formula, and pilot acceptance gates are defined in [representative_path_generation_spec.md](representative_path_generation_spec.md) and `configs/representative_path_selection.json`.

This note defines how MigrationBench should choose and classify migration paths without relying on informal labels such as "in-gap" or "deep penetration" alone.

## Goal

Build a general path-selection framework that works for layered Sb2Te3 now, but can extend to other host materials and migrating species later.

## Unit Of Measurement

A benchmark record is not just a material and a barrier. It is:

```text
host structure + migrating species + start basin + end basin + path initialization + calculator + relaxation protocol + convergence state
```

This means fixed-path MLFF, MLFF self-NEB, and DFT-refined NEB are distinct measurements even when they use the same endpoints.

## Site Descriptor

For each candidate site `s`, compute a descriptor vector:

```text
phi(s) = [
  fractional_z,
  distance_to_nearest_host,
  host_coordination_number,
  local_void_radius,
  layer_gap_score,
  penetration_score,
  local_composition_counts,
  relaxed_site_energy,
  relaxation_displacement
]
```

The exact implementation may evolve, but every descriptor must be generated by script and stored with the dataset.

## Path Descriptor

For a start/end pair `(a, b)`, define a path descriptor over an initialized image sequence `{x_i}`:

```text
Phi(a,b) = [
  path_length,
  max_penetration_score,
  mean_penetration_score,
  min_void_radius_along_path,
  max_coordination_change,
  endpoint_energy_difference,
  MLFF_barrier_proxy,
  TS_location_fraction,
  path_curvature,
  host_relaxation_amplitude
]
```

The continuous descriptors are the primary categories. Human-readable tags such as `in_gap`, `mixed`, and `deep_penetration` are downstream labels derived from these values.

## Selection Rule

1. Generate candidate sites from relaxed structures, MACE-screened interstitial site searches, historical NEB endpoints, and collaborator/Victor site lists.
2. Remove duplicate sites using periodic RMSD or fractional-coordinate clustering.
3. Build candidate pairs within physically meaningful distance and topology windows.
4. Compute `Phi(a,b)` from a cheap path initializer: linear, IDPP, or MLFF-preconditioned NEB.
5. Stratify paths in descriptor space rather than selecting by hand.
6. Pick representative paths by farthest-point sampling within each region of descriptor space.
7. Escalate only selected representatives to QE NEB.

## Task-Relevant Model Error

Traditional force/energy RMSE is not enough because the manuscript claim is about non-equilibrium migration decisions. The benchmark should report:

| Metric | Meaning |
|---|---|
| Fixed-path barrier error | Does the model score the DFT path correctly? |
| Self-relaxed barrier error | Does the model find a plausible path when allowed to move images? |
| TS localization error | Does the model place the transition state at the same reaction coordinate? |
| Path-shape distance | Does the model choose the same geometric mechanism? |
| Ranking error | Does the model choose the same easiest/hardest path ordering? |
| Relaxation energy delta | How much did pre-relaxation alter each image before DFT? |

This converts model evaluation from "global RMSE is low" to "the model preserves the migration decision we need."

## Acceptance Gate

A path becomes manuscript-grade only when:

- start/end basins are uniquely named and reproducible;
- source structures and image generation protocol are recorded;
- MLFF preconditioning manifest exists;
- QE `neb.in` has a paired config manifest;
- DFT output is converged or explicitly accepted as stationary-unconverged with drift/error criteria;
- parser regenerates the barrier and uncertainty/state flags.

## Current Interpretation

The 81-atom `neb_1` to `neb_5` historical paths should be treated as deep-penetration candidates by continuous descriptors. `neb_2`, `neb_3`, and `neb_4` are confidently deep-penetration; `neb_1` and `neb_5` should remain classified by descriptor values rather than memory. Current DFT values are candidates, not final manuscript-grade references.
