## Canonical DFT reference for the in-gap pathway (path 1-4)

**The canonical DFT migration-barrier reference for the in-gap (ID) pathway 1-4 is
E_m = 0.336 eV** (forward activation energy, 5-image NEB,
DFT+D3, `221_vdw_corr_DFT_D3/1-4/`). At the last saved iteration the forward
energy was stationary at 0.335977 -> 0.336050 eV (drift << 0.005 eV), so the
value is numerically stable even though the run file is truncated.

## Why the main text says "0.34 eV", and where any "~0.3 eV" comes from

- **0.34 eV** is simply the two-decimal rounding of the audited 1-4 value
  0.336 eV and is correct for the in-gap pathway quoted in the main text.
- A generic **"~0.3 eV"** for OOD paths 1-2 and 1-3 (see MigrationBench
  `EXPERIMENTS.md` Data Summary table) traces to *converged cluster-side* reruns
  of those paths, not to these local files. The local 1-2 and 1-3 `neb.out` files
  do **not** end with `JOB DONE` (tail lines: 'tcpu =  16385.4    self-consistency for image   5' /
  'tcpu =   4104.8    self-consistency for image   2') and their truncated-state activations are 2.79 and
  4.00 eV -- early-iteration NEB estimates that were still relaxing. They must
  **not** be quoted as DFT references; the canonical 1-2/1-3 references (~0.3 eV,
  per EXPERIMENTS.md) require the converged cluster runs [PENDING-CLUSTER].
- Path 1-5 must be excluded entirely from DFT references: the 10-image rerun
  `1.sep2-2_10img_ea` **diverged** (activation energy printed as
  ~800.5 eV), and neither the original 1-5 run nor the sep2-1 rerun converged.
