# FIG-057 v3 | Dopant-by-path-class task matrix

**Figure 1 | Foundation-model profiles across the three migration classes.** Rows show Cu, Li, Na, and Cr; columns show within-QL, in-gap diffusion, and gap → QL. Colored curves are same-geometry single-point evaluations from ten local Foundation/MPA0 checkpoints. The black curve is the corresponding screened QE path table. The new Cr row uses the three completed Rockfish Cr-substitution trajectories (jobs 31916908–31916910), with 10 images and 81 atoms per path.

The Cr Rockfish jobs completed and produced finite path tables, but all three contain a final SCF-convergence warning; their QE traces and barrier-like values are therefore provisional diagnostic references and are not publication-grade converged activation energies. Exact input, job, model, and hash provenance is retained in the companion Rockfish package. The earlier exploratory 61/81-atom Cr family used in v2 is preserved and is not mixed into this v3 matrix.
