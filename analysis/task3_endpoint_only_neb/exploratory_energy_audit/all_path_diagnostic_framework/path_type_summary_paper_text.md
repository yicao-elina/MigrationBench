# Path-type summary

**Figure X | A clean three-class view of the ten saved NEB path snapshots.** The canonical classes are in-gap diffusion, gap-to-QL migration, and within-QL migration. The Cu path with an unspecified `neb` label is retained as a separate control rather than forced into one of the three classes. Open markers denote paths that fail the exploratory final-table stability screen. All nine Foundation models are included in the error distributions.

The three-class organization separates the physical exam questions while preserving the two unstable paths as explicit evidence. It should be used for stratified diagnosis, not as a claim that the current QE values are converged reference barriers.
