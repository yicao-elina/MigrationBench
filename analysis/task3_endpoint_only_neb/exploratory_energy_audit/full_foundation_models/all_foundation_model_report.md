# Complete local Foundation-model comparison (endpoint-only diagnostic)

This matrix evaluates all nine models in `/Users/alina/Downloads/mace-foundation-models` on eight fresh endpoint-only linear paths (10 frames/path; 80 frames/model). Energies are relative within each path and model. The result is a model-to-model profile comparison, not a DFT-accuracy validation and not a converged NEB barrier. MH-0 and MH-1 use the explicit `omat_pbe` head. The black QE trace uses the corrected `.path` Hartree-to-eV conversion, but its geometries are the retained QE path frames and therefore are not geometry-identical to these fresh linear inputs.

The profile figure shows one line per model for every path, with explicit markers and line segments. The model colors use related Morandi shades within each family. The NEB image-table third column is a force/path residual in eV/A and is retained as a separate audit field rather than being added to the energy as if it were a standard error. The companion residual-audit figure reports that quantity against each path's `path_thr`. The spread figure reports each model's RMSE to the across-model median profile and the path-level barrier-like envelope. For a quantitative QE comparison on identical geometries, use `../corrected_dft_foundation_models/`.
