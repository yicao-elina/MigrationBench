- fixed-path 行标记为 `FINITE_DIAGNOSTIC`，表示固定路径单点打分，不是自洽迁移势垒。
- self-relaxed 行标记为 `ENDPOINT_ONLY_MLIP_NEB_PROXY`；本轮 12/12 为
  `CONVERGED`，但它是固定端点、ASE-IDPP 初始化的 MLIP NEB proxy，不是 DFT MEP。
- DFT 参考仍为 `COMPLETED_BUT_SCF_WARNING`，仅作为筛选参考上下文保留。
- 为保持 Scratch 的 fixed/self 内部可配对，本交付使用 Rockfish Lmax1 paired
  checkpoint；其 SHA256 与旧 fixed R04 图中的 Scratch 行不同。该差异已写入
  `SCRATCH_CHECKPOINT_AUDIT.tsv`，因此本图的 manifest 状态为
  `PASS_WITH_SCIENTIFIC_BOUNDARIES`、render status 为 `RECONSTRUCTION`，发布前应
  按该审计确认所需的 Scratch checkpoint lineage。
