# Foundation self-relaxed 4×3 NEB profiles with QE/DFT reference traces

Foundation-model self-relaxed, endpoint-only NEB profiles for Cr, Cu, Li, and Na in Sb₂Te₃. Rows are ordered Cr, Cu, Li, and Na; columns are in-gap diffusion, gap→QL, and within-QL migration. Each colored trace is the mean relative energy over the accepted Foundation models in its model family, with the translucent band showing the within-family standard deviation: MACE-MP (n=5), MACE-OMAT-0 (n=2), and MACE-MH (n=2). Energies are referenced to the initial image of each path and the colored curves use the normalized ten-image coordinate, s; the plotted x-axis is labelled **Reaction Coordinate**.

The dark dashed line with open diamonds is the available QE/DFT reference trace; the figure legend abbreviates this layer as **DFT-NEB**. Its full status is **QE/DFT reference · SCF warning; diagnostic** because the source rows retain SCF-warning or failed-SCF-convergence status. The reference traces are canonical fixed-path single-point NEB diagnostics, aligned for display by image index (i/9); they are not same-geometry DFT rescoring of the self-relaxed MLFF images, validated DFT minimum-energy paths, or unconditional ground truth. The Cr source coordinate is nonuniform and is retained separately in `GROUND_TRUTH_REFERENCE_MANIFEST_R03.json`; it is not silently used as the overlay coordinate.

The MLFF campaign contains 108/108 accepted element×path×model rows. Each accepted run uses the canonical endpoint pair, endpoint-only IDPP initialization, ten images, and deterministic seed 42. The colored profiles remain self-relaxed MLFF observables and diagnostics rather than DFT barriers or unconditional physical rankings. Historical nonconverged retry attempts remain in the attempt ledger and raw-artifact index but are excluded from the accepted class profiles. No Blender or molecular-rendering layer is included.

The visual grammar follows the archived authoritative R03 reference standard recorded in `figures/VISUAL_QA_R03.json`. Legacy raw stems, including `2L-Cu__...`, are aliases and do not change the canonical element identities.
