# DFT-SINGLE-POINT-GATE

## Article target
Results/SI: DFT validation coverage and acceptance boundary

## Caption
Candidate-level status of the independent DFT single-point wave, separated into stable endpoints, NEB intermediates, near-saddle structures, and failure-evidence frames.

## Results
All 20 audited candidates are marked not accepted: 5 stable endpoints, 5 NEB intermediates, 5 near-saddle structures, and 5 failure-evidence frames. The current table contains no accepted finite DFT energy/force values.

## Discussion
This figure is a transparent negative/gate result. It explains why MACE candidate tables cannot yet be paired with an accepted DFT target, and it prevents a missing-output campaign from being mistaken for a zero-error benchmark.

## Scientific boundary
- Pending/missing QE output is not treated as a scientific zero.
- The MD snapshot subset also retains an explicit missing-provenance gate.
- This figure should not be used as a DFT energy/force plot.
